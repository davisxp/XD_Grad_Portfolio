# Security Policy

## Supported Versions

The following table shows which versions of this project currently receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1  | :white_check_mark: |
| 0  | :x:                |

Only the latest stable release receives security patches. Older versions are no longer maintained.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

- Email: xavier@mainsail.plus.com  
- Alternatively, open a **private** issue on the repository if supported.

When submitting a report, include as much detail as possible: the affected version, reproduction steps, potential impact, and any suggested mitigations.

You can expect an acknowledgment within **72 hours** and a full response (confirmation, fix timeline, or rejection) within **7 days**.  
Confirmed vulnerabilities will be patched promptly, and a disclosure will follow once the fix has been released.
